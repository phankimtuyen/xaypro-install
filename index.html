XâyPro

Android • v1.2.0

Ứng dụng quản lý xây dựng cho Android (Kotlin/Compose). Tải file cài đặt APK bên dưới. Nếu điện thoại chặn tải trong app Grok, hãy mở trang này bằng Chrome hoặc tải trên máy tính rồi gửi qua Zalo.

Tải XayPro.apk

Sau khi tải xong, mở file → nếu máy hỏi thì bật “Cho phép cài từ nguồn này”.

Cách chắc chắn nhất

  1. Mở cuộc chat XâyPro trên máy tính (Chrome).
  2. Bấm Tải XayPro.apk ở trên.
  3. Gửi file qua Zalo cho điện thoại này.
  4. Mở file trên điện thoại → Cài đặt.
  5. Đăng nhập bằng tài khoản demo bên dưới.
